# 👥 UserDirectory

> Справочник пользователей — карточки с аватарами, скиллами и живым поиском по имени.

## 🎯 О проекте

Мини-приложение на чистом JavaScript: загружает список пользователей из 
JSON-файла и рисует их в виде карточек. Вверху есть поиск — при вводе 
имени список фильтруется в реальном времени.

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как пользоваться

1. Открой `index.html` в браузере
2. Смотри карточки пользователей (аватар, имя, возраст, город, email, статус, скиллы)
3. Введи имя в поиск — список фильтруется моментально
4. Счётчик «Найдено» показывает количество совпадений

## 🛠️ Технологии

- HTML5 (input, grid-раскладка)
- CSS3 (Grid, карточки, бейджи скиллов)
- JavaScript (Vanilla)
- **Fetch API** — загрузка данных из `users.json`
- Массивы и методы: `forEach`, `map`, `filter`, `join`
